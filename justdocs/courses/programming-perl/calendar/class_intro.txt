課程簡介：Perl Programming

本課程以 Perl 程式設計語言為核心，介紹程式設計的基本觀念與實務應用。Perl 是一種歷史悠久、功能強大的程式語言，特別擅長 文字處理、檔案處理、資料分析及系統管理自動化，至今仍廣泛存在於 Unix/Linux 系統與既有軟體環境中。

課程將以《Perl 學習手冊（第七版）》為主要參考教材，由基礎語法循序進入較完整的程式設計技巧。內容包括：

Perl 程式的基本結構與執行方式
Scalar、Array、Hash 等基本資料型態
條件判斷與迴圈控制
字串與檔案處理
Regular Expression（正規表示式）
Subroutine（副程式）
List、Array 與 Hash 的進階運用
Reference（參照）與複合資料結構
Perl 在 Unix/Linux 環境中的實際應用

本課程強調 實際撰寫程式與問題解決能力，學生將透過大量範例及練習，學習如何將問題轉換成程式邏輯，並利用 Perl 處理文字、檔案及結構化資料。

完成本課程後，學生應能獨立撰寫中小型 Perl 程式，並具備進一步學習 資料結構、系統程式設計、Unix/Linux 工具開發及自動化程式設計的基礎。
